The new [T.SetTimeout] method (and the corresponding [TB] interface method)
sets a per-test timeout: the maximum time a single test may spend actively
running before the test binary is aborted. The timer is paused while a test is
blocked in [T.Parallel] or waiting for a subtest started with [T.Run], and it
is inherited by subtests. The `go test` command applies a default per-test
timeout of one minute, configurable with the new `-testtimeout` flag.
